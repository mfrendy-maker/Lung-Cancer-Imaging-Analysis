# Lung CT Lesion Analysis

Research demo that marks suspected lesions on a lung CT image and colours them by size-based severity.
Source code and documentation: https://github.com/mfrendy-maker/Lung-Cancer-Imaging-Analysis

This is an unvalidated research tool. It is not a medical device and must not be used for diagnosis. Uploaded images are
analysed in memory and never saved. Please use only sample or anonymised images.

Access is protected by a code set in the Space secret `LUNG_GUI_TOKEN`.
